About this library

Public reference library for AI, data and pharmaceutical regulation. Everything here comes from public sources. Each document page names its source and licence.

Full text and PDFs appear only when the licence allows them to be republished. Other documents show their details and a link to the source.

This is a personal reference collection. It isn't legal advice and isn't an official publication of any authority. Always check the source for the current version of a text.

Search by meaning

This option finds passages that say the same thing in other words or another language. It's off until you turn it on. Your browser then downloads an open model from Hugging Face and the code that runs it from jsDelivr, and compares your search with the library on your own device, so what you type isn't sent anywhere. Those two services can see the download.

Ask quick questions in another tool
